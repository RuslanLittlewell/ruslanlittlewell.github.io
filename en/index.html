Easy Baby Timer

iOS · App Store

An iOS app for tracking a baby's sleep, feeding and awake time with one-tap timers and gentle reminders. Private by design: all data stays on the device, it works fully offline and needs no account.

Built solo with React Native and Expo, from the first prototype to the App Store release. The interface is fully translated into 5 languages and switchable in-app at any time.

The most interesting part was the native layer: a SwiftUI Live Activity widget that shows a running timer in the Dynamic Island and on the Lock Screen, plus optional multi-parent sync on Supabase with row-level security — while the app stays fully usable offline.

Key features

  • One-tap timers for sleep, feeding and awake time
  • Live Activity in the Dynamic Island and on the Lock Screen
  • Smart reminders based on the baby's own schedule, with feeding auto-stop
  • Day timeline calendar, colour-coded by activity, with pinch-to-zoom from a full day down to the minute
  • Entry editing, milk amount logging and daily stats
  • Floating mini-timer that follows you across the app while a timer runs
  • Shared access to a child between parents via an invite code
  • Offline-first local storage, no account, no ads
