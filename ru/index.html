Easy Baby Timer

iOS · App Store

Мобильный бэби-трекер для отслеживания сна, кормлений, засыпания и периодов бодрствования: таймеры в один тап, подробная статистика и совместный доступ для родителей и других близких.

Спроектировал и разработал приложение с нуля: архитектуру, UI/UX, локальное хранение данных, облачную синхронизацию, аутентификацию, локализацию и платформенные функции.

Реализовал offline-first архитектуру: локальные изменения сохраняются в персистентной очереди и синхронизируются с Supabase после восстановления соединения. Слой синхронизации поддерживает устойчивые к конфликтам обновления, удаления, общие профили и Live Activities, запущенные на другом устройстве.

Разработал кастомный календарный таймлайн с масштабированием жестами, визуализацией активностей в реальном времени, навигацией между периодами и подробной статистикой.

  • Дневной, недельный и месячный виды календаря

  • Расписания сна и рекомендации по режиму с учётом возраста

Mediatool

Enterprise · ТВ / broadcast

Enterprise-платформа для ТВ и медиа: управление контентом, планирование эфирной сетки, координация задач и контроль выдачи в эфир для вещательных каналов.

Разрабатывал и поддерживал крупную платформу управления медиа на React - для планирования, организации, валидации и мониторинга эфирного контента. Система закрывает сложные сценарии планирования, работу с метаданными, живые операции с плейлистами, обновления в реальном времени, ролевой доступ и настройку нескольких каналов.

  • Content Manager: программы, эпизоды, промо, реклама, ID, блоки, метаданные, сегментация, музыкальные метки и ран-логи
  • Модуль Planner для сборки эфирных сеток: макро- и микроблоки, drag-and-drop, автозаполнение, расстановка рекламы, импорт/экспорт плейлистов, выгрузка CSV/XLS и синхронизация расписаний
  • Модуль Workflow: задачи, таймлайны, лейблы, участники, назначения, живые обновления, фильтрация, поиск и экспорт
  • Модуль Playout: эфирные расписания, микро- и макропредставления, dummy-события, метаданные, порядок событий и операции на уровне дня
  • Playlist Checker и алерты: битые файлы, статус эфира, глобальные системные оповещения и операционные проблемы
  • Live-мультивьюер с несколькими плеерными бэкендами: HTML5/WebRTC, SLDP, MSE и Redge
  • Ролевая навигация и права для аккаунтов planner, playout, global, admin и supervisor
  • Адаптивная мобильная версия дашборда, workflow, live-превью и мониторинга событий
  • Глобальные и канальные настройки: AV, FTP, метаданные, почта, workflow, planner, playout и playlist checker
  • Обновления в реальном времени через WebSocket для данных planner и workflow
  • Авторизация, восстановление пароля, настройки пользователя, профиль, уведомления и сценарии двухфакторки

Разработал систему на React + TypeScript на фронтенде и Node.js на бэкенде, с real-time архитектурой на WebRTC. Платформа поддерживает переподключаемые пиринговые сессии и мульти-пир соединения, что даёт стабильную связь даже при нестабильной сети.

Проект требовал сложной синхронизации состояния в реальном времени, управления жизненным циклом пиров и кроссплатформенной упаковки под Electron - с упором на надёжность и низкие задержки.

VPN

с AI-агентами

Full-stack VPN-платформа с двумя сетевыми связками: AmneziaWG на базе WireGuard и VLESS + Reality + XTLS-Vision поверх raw TCP.

Сделал сайт на Astro/React, Telegram-бота, админ-панель, биллинговые вебхуки, автоматическую выдачу VPN-конфигов, учёт трафика, управление жизненным циклом подписок и инфраструктуру деплоя на Docker.

Реализовал AmneziaWG-туннели с WireGuard-шифрованием и UDP-обфускацией, а также DPI-устойчивую связку VLESS + Reality + XTLS-Vision без WebSocket/gRPC. Provisioning VLESS построен через Remnawave REST API и Xray-ноды: создание, блокировка и удаление пользователей, выдача постоянных subscription-ссылок и синхронизация доступа с биллингом.
